AI-901 cheat sheet 1/5 — AI workloads and responsible AI

One page. Facts snapshot 2026-11; verify current behaviour on Microsoft Learn before the exam.

The family tree

TermDefinition and memory hook
Artificial intelligenceSystems that reason, perceive, learn, and understand language. The umbrella term.
Machine learningModels learn patterns from data instead of hand-written rules.
Deep learningML using neural networks with many hidden layers; needs more data and compute.
Generative AICreates new text, images, audio, or code from a prompt.
AgentA language model plus instructions plus tools; can plan and act.

Generative AI is one application of AI, not a synonym for it.

AI workloads

WorkloadWhat it does
Computer visionInterprets images and video: classify, detect, read text, caption.
Natural language processingExtracts meaning from text: sentiment, entities, key phrases, summaries.
SpeechAudio to text, text to audio, or speech between languages.
Conversational AIHolds a dialogue through a bot or agent.
Predictive analyticsForecasts future numeric outcomes from history.
RecommendationSuggests items from user and item behaviour.
Anomaly detectionFinds observations that differ from normal.
Information extractionTurns documents into structured fields.

Machine learning task types

TaskOutput and label need
ClassificationA class or category. Supervised with labels.
RegressionA continuous number. Supervised with labels.
ForecastingA future number from a time series. Supervised.
ClusteringGroups of similar records. Unsupervised, no labels.
Anomaly detectionUnusual records; usually unsupervised.

A named category means classification; a quantity means regression; future time-ordered values mean forecasting.

Computer vision scenarios

ScenarioTask
One label for the whole imageImage classification
A label and a box per objectObject detection
Text read from a photo or scanOptical character recognition
Fields such as vendor and totalDocument Intelligence
Whether a face exists, pose or blurFace detection
Who a face belongs toFace recognition (Limited Access)

Responsible AI

PrincipleDemands and typical control
FairnessEquitable treatment; test outcomes across groups and balance data.
Reliability and safetyPredictable operation and safe failure; thresholds and fallbacks.
Privacy and securityProtect data; encryption, access control, PII redaction.
InclusivenessUsable by everyone; captions, translation, accessibility.
TransparencyDisclose AI use, behaviour, and limits.
AccountabilityPeople stay answerable; ownership, review boards, audit.

Matching requirements to workloads

Requirement keywordWorkload
Image, photo, video, camera, shelfComputer vision
Review, email, contract, text, languageNatural language processing
Audio, voice, transcription, captionsSpeech
Chat, bot, dialogue, self-serviceConversational AI
Forecast, demand, next month, revenuePredictive analytics
Customers also bought, personaliseRecommendation
Unusual, outlier, fraud, deviationAnomaly detection

Exam traps

  • All deep learning is ML; not all ML is deep learning.
  • Two classes or five classes are both classification.
  • Detection answers what and where, with a bounding box.
  • Recognition is audio to text; synthesis is text to audio.
  • Unequal outcomes is fairness; disclosure is transparency; governance is accountability.
  • Content filters and prompt shields are generative-AI safety controls, not a workload.

AI-901 cheat sheet 2/5 — Machine learning on Azure

One page. Facts snapshot 2026-11; verify current behaviour on Microsoft Learn before the exam.

Features, labels, and data splits

TermMeaning and house-price example
FeatureInput variable: bedrooms, floor area, location.
LabelTarget to predict: selling price.
Training setFits the model parameters.
Validation setTunes hyperparameters and compares candidates.
Test setFinal unbiased estimate on unseen data; touched once.

Data leakage — test rows inside training data — inflates the score. Tuning on the test set turns it into a validation set.

Supervised vs unsupervised

SupervisedUnsupervised
Training dataFeatures and labelsFeatures only
GoalLearn a mapping to a targetFind structure or groups
TasksClassification, regression, forecastingClustering, anomaly detection
ExamplePredict churn: yes or noSegment customers

Supervised tasks

TaskOutput and example
Binary classificationTwo classes: fraud or legitimate.
Multi-class classificationThree or more classes: five ticket categories.
RegressionContinuous number: price, temperature.
ForecastingFuture number from time series: demand next quarter.

Model evaluation

MetricFormula or meaning; when to use
AccuracyCorrect ÷ all. Only useful when classes are balanced.
PrecisionTP ÷ (TP + FP). False alarms are expensive.
RecallTP ÷ (TP + FN). Missing a positive is expensive.
F1 scoreHarmonic mean of precision and recall. Imbalanced classes.
RMSERoot mean squared error in target units. Punishes large errors.
MAEMean absolute error in target units. Every error counts equally.

Confusion matrix: TP true positive, TN true negative, FP false positive, FN false negative. Missed fraud is a false negative, so raise recall. Legitimate mail marked spam is a false positive, so raise precision.

Accuracy can be 95% while the model misses every positive case. Check precision and recall on imbalanced data.

Overfitting and underfitting

SymptomDiagnosis and remedy
Great on training, poor on new dataOverfitting. More data, simpler model, regularisation, early stopping.
Poor on training and testUnderfitting. Richer model, better features, longer training.

Azure Machine Learning

AssetPurpose
WorkspaceTop-level container for experiments, data, compute, models, endpoints.
Compute instanceManaged workstation for notebooks and interactive work.
Compute clusterScalable multi-node training; scales to zero when idle.
DatastoreConnection details for Azure Blob or Data Lake storage.
Data assetVersioned reference to data used by experiments.
EnvironmentReproducible packages and dependencies.
Model registryVersions and tracks trained models.
PipelineRepeatable prepare, train, evaluate, deploy steps.
DesignerDrag-and-drop canvas for pipelines.
Automated MLTries algorithms and hyperparameters, ranks by a primary metric.
Online endpointReal-time REST predictions.
Batch endpointScheduled or on-demand scoring of large datasets.

AutoML supports classification, regression, and forecasting. You choose the primary metric (accuracy, recall, RMSE); it selects the best trial by that metric.

Deployment and operations

NeedChoose
Prediction per requestOnline endpoint
Overnight scoring of millions of rowsBatch endpoint
Explore algorithms without codeAutomated ML
Build a pipeline visuallyDesigner
Reproduce and audit an experimentVersioned data, code, pipelines (MLOps)
Detect drift after launchModel monitoring

Lifecycle: collect → prepare → train → validate → test → deploy → monitor → retrain.

Exam traps

  • Features go in, labels come out. Price is the label; bedrooms are features.
  • A target column means supervised learning; no target means clustering.
  • Accuracy alone hides failure on imbalanced data.
  • Validation guides choices; the test set reports the final score.
  • Compute instance is for authoring; compute cluster is for scale-out training.
  • AutoML is a search over algorithms, not a model type.
  • Azure ML trains custom models; Microsoft Foundry builds generative apps and agents.

Azure AI Vision

CapabilityOutput
CaptionOne sentence for the whole image.
Dense captionsSeveral captions, each tied to a region.
TagsKeywords such as outdoors, person, building.
ObjectsA label and bounding box per object.
Read (OCR)Printed and handwritten text as lines and words with positions.
Smart croppingCrop coordinates that keep the main subject visible.
People detectionLocations of people in the image.

Vision Studio is a browser playground for trying these features on sample or uploaded images without code.

Classification vs object detection

Image classificationObject detection
QuestionWhat is in the image?What is where?
OutputOne or more labels for the whole imageA label and a box per object
Several objectsNot locatedEach object reported separately
ExamplePhoto contains a dogDog at (x1, y1, x2, y2); cat at (x3, y3, x4, y4)

If the requirement mentions position, count, or multiple items, choose object detection.

OCR vs Document Intelligence

OCR (Vision Read)Document Intelligence
InputPhoto, sign, scan, pageForms, invoices, receipts, IDs
OutputText and word positionsStructured fields, tables, key-value pairs
LayoutLines and wordsSections, tables, selection marks
Best forUnstructured text in an imageBusiness documents with a known schema

OCR gives you text. Document Intelligence gives you meaning: which number is the total, which date is due.

Document Intelligence models

ModelExtracts
ReadText, lines, words, languages.
LayoutText, tables, selection marks, headers, reading order.
InvoiceVendor, customer, invoice date, due date, line items, subtotal, tax, total.
ReceiptMerchant, transaction date and time, line items, tax, total.
Identity documentName, date of birth, document number, expiry from passports and ID cards.
Business cardName, company, phone, email, address.
Custom templateYour fields from consistent forms.
Custom neuralYour fields from forms with more layout variation.
Custom composedA collection of models, routed automatically.

Choose custom when the prebuilt schema does not match your document.

Custom Vision

Project typeOutput and labelling
Image classificationOne or more labels for the whole image; tag each image.
Object detectionA label and box per object; draw a box around each object.

Custom Vision is supervised: upload and label your own images, train, evaluate, and publish a prediction endpoint. Use it when prebuilt models do not cover your classes.

Face

CapabilityQuestion it answers
Face detectionIs there a face, and what is its pose, blur, exposure, or occlusion?
Face verificationDoes this face match the claimed person? One-to-one.
Face identificationWhich person in a group matches this face? One-to-many.
Liveness detectionIs a real person present, rather than a photo, video, or mask?

Limited Access: identification and verification need approval and responsible AI safeguards. Detection is broadly available. Recognition is not detection.

Choosing a service

RequirementService or task
Describe a photo, tag it, crop a thumbnailAzure AI Vision image analysis
Read text from a sign or scanned pageAzure AI Vision Read (OCR)
Extract fields from invoices or receiptsDocument Intelligence prebuilt model
Extract fields from your own formDocument Intelligence custom model
Classify your product photosCustom Vision image classification
Find and locate products or defectsCustom Vision object detection
Prevent photo spoofing in face sign-inLiveness detection

Exam traps

  • Azure AI Vision is prebuilt; Custom Vision trains on your labelled images.
  • Document Intelligence is built on OCR but adds structure.
  • Layout is not the invoice model; the invoice model returns business fields.
  • Bounding boxes mean detection, not classification.
  • Face detection does not identify anyone.
  • Smart cropping suggests a crop; it does not remove objects.
  • Vision Studio is a playground, not a production endpoint.

AI-901 cheat sheet 4/5 — Natural language processing on Azure

One page. Facts snapshot 2026-11; verify current behaviour on Microsoft Learn before the exam.

Typical NLP flow

Input text → language detection → sentiment / key phrases / entities → structured output

Language detection usually runs first so later models know which language rules to apply.

Azure AI Language

CapabilityWhat it returns
Language detectionDetected language and confidence score.
Sentiment analysisPositive, negative, neutral, or mixed, with scores; optionally per sentence.
Opinion miningSentiment tied to specific aspects or targets.
Key phrase extractionThe main concepts and terms.
Named entity recognitionTyped entities: person, organisation, location, date, quantity.
PII detectionPersonal data found, with optional redaction.
SummarisationA short version of long text, including conversations.
Question answeringThe best answer from a curated knowledge base, with confidence.
CLUThe predicted intent and extracted entities.

Language Studio is a browser playground for testing these features without code.

Sentiment and opinions

TermMeaning
Document sentimentOverall label and confidence for the whole text.
Sentence sentimentA label per sentence, so one bad paragraph does not hide the rest.
Opinion miningLinks an opinion to its target: location positive, room service negative.

Sentiment tells you how someone feels; opinion mining tells you what they feel it about.

Entities vs key phrases

Named entity recognitionKey phrase extraction
OutputTyped entities with categoriesImportant terms and phrases
ExamplePerson: Ada Lovelace; Location: Paris; Date: 12 May"supplier contract", "delivery delay"
UseExtract people, places, organisations, datesIndex, search, topic review

PII detection is a specialised entity task: it finds names, phone numbers, and addresses and can return redacted text.

Summarisation

TypeHow it works and trade-off
ExtractiveSelects existing sentences. Faithful wording, but can be disjointed.
AbstractiveGenerates new wording. Fluent, but must be checked for accuracy.
ConversationSummarises a dialogue into issues, resolution, and follow-ups.

Question answering vs CLU

Question answeringConversational language understanding
PurposeRetrieve an answer from curated contentDecide what the user wants to do
InputA questionAn utterance
OutputAnswer text, source, confidenceIntent and entities
Built fromFAQs, documents, URLsLabelled utterances
Example"What is the returns window?" → 30 days"Cancel my order" → CancelOrder, order id

Predictable FAQ-style answers point to question answering. A bot that must choose an action points to CLU.

CLU concepts

TermMeaning and example
IntentThe user's goal: BookFlight, CancelBooking, Complain.
EntityA detail that fills in the intent: Destination Paris; Date Friday.
UtteranceA labelled example phrase: "I need a flight to Paris on Friday".

More varied, correctly labelled utterances produce a more robust model.

Translation and speech

CapabilityWhat it does
Text translationConverts text between languages; can auto-detect the source.
Document translationTranslates whole documents and preserves structure.
Custom glossaryForces brand or domain terms to translate consistently.
Speech to textTranscribes spoken audio.
Text to speechSynthesises spoken audio from text.
Speech translationRecognises speech in one language and outputs another, as text or speech.

Language detection identifies the language; translation converts it. Recognition is audio to text; synthesis is the reverse.

Choosing a service

RequirementCapability
Is this review positive or negative?Sentiment analysis
Which product does the customer mention?Named entity recognition
What is this document about?Key phrase extraction
Which language is this?Language detection
Hide names before sharingPII detection and redaction
Summarise a long call transcriptSummarisation
Answer FAQs from a knowledge baseQuestion answering
Decide book versus cancelCLU intent recognition
Translate into 12 languagesAzure AI Translator
Voice in French, voice out in EnglishSpeech translation

Exam traps

  • Question answering retrieves; CLU classifies intent.
  • Intent is the goal; entities are the details.
  • Key phrases are topics; entities are typed things.
  • PII detection is privacy, not topic discovery.
  • Extractive copies sentences; abstractive writes new ones.
  • Azure AI Language analyses text; Azure OpenAI generates it.

AI-901 cheat sheet 5/5 — Generative AI on Azure

One page. Facts snapshot 2026-11; verify current behaviour on Microsoft Learn before the exam.

Core terms

TermMeaning
Foundation modelLarge model pretrained on broad data, adaptable to many tasks.
Large language modelFoundation model trained to predict and generate token sequences.
TokenUnit of text: a word, part of a word, or punctuation. Cost and context use tokens.
Context windowMaximum input plus output tokens considered at once.
DeploymentA named hosted instance of a model, called through an endpoint.

Anatomy of a request

System prompt sets role and rules, user prompt carries the request, grounding data supplies evidence, and the model returns a completion. Earlier assistant messages can be replayed as history.

Prompting techniques

TechniqueWhat you do and when
Zero-shotAsk with no examples; simple, well-known task.
Few-shotInclude a few worked examples; output format matters.
Role and formatSet a role and an output shape (JSON, table, length) in the prompt.
GroundingSupply source text and require the answer to use it; current or private facts.

Prompt engineering changes the request, not the model weights. Try it before paying for fine-tuning.

Generation settings

SettingEffect and typical choice
TemperatureHigher is more random and creative; lower is focused and repeatable. Low for facts.
Top-p (nucleus)Smallest token set whose cumulative probability reaches p. Tune one setting at a time.
Max output tokensCaps completion length; controls cost and truncation.

Azure OpenAI and Foundry

ComponentPurpose
Azure OpenAI in Foundry ModelsOpenAI models with Azure identity, networking, content filtering, compliance.
Microsoft FoundryModel catalogue, playgrounds, deployments, evaluations, agents, governance.
Deployment and endpointHost a model with a name and capacity; call it with a key or managed identity.
EvaluationMeasure quality, groundedness, relevance, and safety before release.

Azure OpenAI hosts generative models with Azure controls. Azure AI Language, Vision, and Speech are prebuilt task services. Azure Machine Learning trains custom classical models.

RAG — retrieval-augmented generation

User question → retrieve relevant chunks → add to prompt → model answers → citations
StepTypical service and why
Index and retrieveAzure AI Search. Keyword, vector, or hybrid search over your content; fetch the best chunks.
AugmentPrompt construction. Put evidence and instructions in the context window.
GenerateAzure OpenAI deployment. Answer using the supplied evidence.
CiteApplication. Let users verify the answer against sources.

RAG reduces hallucinations but does not guarantee truth. Use it for private content and knowledge that changes often.

Hallucination, grounding, and citations

TermMeaning
HallucinationFluent, confident output that is false or unsupported.
GroundingSupplying source evidence so the answer is based on it.
CitationA link from a claim back to the retrieved source.

Reduce hallucination with retrieval, a strict instruction to use only supplied sources, citations, lower temperature, and human review for high-impact decisions.

Prompting vs RAG vs fine-tuning

ApproachChanges, best for, cost
Prompt engineeringChanges the request. Tone, format, quick iteration. Lowest cost.
RAGChanges context at query time. Current or private facts, citations. Medium.
Fine-tuningChanges model weights with examples. Consistent style or narrow task. Highest.

Fine-tuning teaches behaviour and format; RAG supplies knowledge. If facts change weekly, use RAG.

Responsible generative AI

ControlWhat it does
Content filtersAssess prompts and completions for hate, sexual, violence, and self-harm, with severity thresholds.
Prompt shieldsDetect jailbreaks and indirect prompt injection, including hidden document instructions.
Human oversightReview outputs before high-impact decisions such as hiring, credit, or healthcare.
Evaluation and monitoringTest quality, safety, and groundedness before release, then watch production traffic.

Content filters handle harmful content; prompt shields handle prompt attacks. Neither replaces human review.

Copilot and agents

ConceptWhat it is
Microsoft 365 CopilotAssistant in Word, Excel, Outlook, and Teams; uses content the user can already access.
Copilot StudioLow-code builder for custom copilots and agents: topics, connectors, knowledge.
AgentA language model plus instructions plus tools.
ToolsKnowledge tools retrieve; action tools send mail or update a record.

Exam traps

  • Tokens are text units, not credentials or pixels.
  • A bigger context window does not make output true.
  • Higher temperature increases variety, not safety.
  • RAG grounds answers; fine-tuning changes behaviour.
  • Citations make answers verifiable; they do not prove them.
